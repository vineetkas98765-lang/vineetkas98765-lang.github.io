## Publish free with GitHub Pages
1. Download and extract this ZIP.
2. Sign in to https://github.com/ or create a free account.
3. Create a public repository named `YOURUSERNAME.github.io`, replacing YOURUSERNAME with your GitHub username.
4. Upload `index.html`, `style.css`, and `script.js` to the repository root.
5. Open the repository's Settings → Pages. If needed, enable publishing from the `main` branch and `/ (root)`.
6. Your website should appear at `https://YOURUSERNAME.github.io` after GitHub Pages finishes publishing.

## Google search
